## Overview
Faxbot is the only known open‑source, self‑hosted fax server and API — and (as far as known) the only fax server supporting distinct inbound versus outbound provider routing. This enables cost optimization, reliability diversity, and compliance flexibility (HIPAA‑aligned) without vendor lock‑in.

## Key Features
- Dual inbound/outbound provider routing for cost and redundancy
- Policy & failover logic for resilient delivery
- HIPAA‑aligned privacy posture (self‑hosted, auditable)
- Clean REST API + MCP integration (AI assistants can send/receive faxes with structured, auditable actions)
- Docker deployment for straightforward rollout
