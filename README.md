## 🚀 Quick Start

To run this portfolio locally:

```bash
# Clone the repository
git clone https://github.com/DMontgomery40/Portfolio.git
cd Portfolio

# Install Jekyll and dependencies
bundle install

# Run locally
bundle exec jekyll serve

# Visit http://localhost:4000/Portfolio/
```
