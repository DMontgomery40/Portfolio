# Portfolio Screenshots

This directory contains screenshots documenting the portfolio website and projects.

## Recommended Filenames

- `homepage-hero.png` - Hero section of the homepage
- `featured-projects.png` - Featured projects section
- `pentest-mcp-detail.png` - Pentest MCP project detail page
- `homelab-diagram.png` - Homelab architecture diagram
- `messaging-return-details.png` - Secure anonymous messaging returns interface
- `faxbot-ios-txt-to-fax.png` - Faxbot iOS text-to-fax interface
- `faxbot-ios-connect.png` - Faxbot iOS connection interface

## Usage

Screenshots can be referenced in PR descriptions and documentation using relative paths:
```
assets/portfolio-screenshots/filename.png
```

Or with absolute URLs:
```
https://raw.githubusercontent.com/DMontgomery40/Portfolio/gh-pages-md/assets/portfolio-screenshots/filename.png
```
