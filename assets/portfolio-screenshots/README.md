# Portfolio Screenshots

This directory contains screenshots and visual assets for the portfolio site.

## Recommended Files

The following filenames are recommended for portfolio documentation:

- `homepage-hero.png` - Screenshot of the main homepage hero section
- `featured-projects.png` - Screenshot of the featured projects section
- `pentest-mcp-detail.png` - Detail view of the Pentest MCP project page
- `homelab-diagram.png` - Homelab architecture diagram
- `messaging-return-details.png` - Secure anonymous messaging system interface
- `faxbot-ios-txt-to-fax.png` - Faxbot iOS text-to-fax interface
- `faxbot-ios-connect.png` - Faxbot iOS connection screen

## Usage

Screenshots can be referenced in markdown files using:

```markdown
![Alt Text]({{ site.baseurl }}/assets/portfolio-screenshots/filename.png)
```

Or in HTML:

```html
<img src="{{ site.baseurl }}/assets/portfolio-screenshots/filename.png" alt="Description" style="max-width: 100%; height: auto;">
```
